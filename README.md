# VJudge-Spider-on-TravisCI-2025 维护与更新By杜可

>  本身根本不会爬虫，为了给新生算分对这个代码缝缝补补才得以实现。
>  提前说明，由于对run.py的改动较大，现在需要配合create.py才能正常运行
>  本代吗优化点主要有三个
>  1.更快的执行效率，去除了不必要的代码 2.经测试macOS和windows均可完美执行 3.增加了历史数据与错误判断，避免代码在运行一半崩溃导致数据错乱

# 为方便后续算分，建议要求所有同学在vj平台的nickname统一为自己姓名，不加专业以及其他信息
# 更新内容

1. 对于之前师哥开发的get_url.py,发现存在诸多不便，比如有一场比赛爬去错误后需要重新爬去，或者比赛场次过多无法获取到之前的比赛，并且有时候如果有人比赛名称错误会导致错误爬去之类的。为了避免这些问题，我认为程序处理并不是最佳方案。故创建了create.py和all_rul.txt.
2. 加分细则可以通过修改run.py中的socre类中的数值来实现
# 使用说明

1. 将需要爬去的比赛链接加入到all_url.txt(不需要#rank最后后缀)
2. 如果需要爬去所有比赛，请删除out.scv
3. 运行create.py

create.py中有两个函数，getall是用来爬去所有比赛的需要清空out.csv
getlasted需要传入爬取比赛链接，但无论哪种方式都会叠加到out.csv
所以需要注意是大家的名字nickname不要轻易修改

# 注意

在history文件夹中会显示每场比赛的具体情况，但是师哥之前的程序会把结果叠加到out.csv 上
